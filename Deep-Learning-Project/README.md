# Fashion Image Classification Using Deep Learning

## Project Overview
This project implements and compares Artificial Neural Network (ANN) and Convolutional Neural Network (CNN) models for classifying clothing images using the Fashion-MNIST dataset.

## Dataset
- Dataset: Fashion-MNIST
- Total Images: 70,000
- Training Images: 60,000
- Testing Images: 10,000
- Categories: 10 clothing classes

## Technologies Used
- Python
- TensorFlow / Keras
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Methodology
1. Dataset Loading
2. Data Preprocessing
3. ANN Model Implementation
4. CNN Model Implementation
5. Model Training and Evaluation
6. Performance Comparison
7. Visualization of Predictions

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

## How to Run
1. Download the `.ipynb` notebook.
2. Open it in Google Colab.
3. Select Runtime → Run all.
4. Wait until both models finish training.
5. View the evaluation results and predictions.
